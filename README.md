## What This Project Does

- **Multi-Household Management**: Users can create or join multiple households to share pantry items and recipes
- **Pantry Tracking**: Keep track of ingredients with quantities, expiration dates, and categories
- **Recipe Management**: Store and organize recipes with ingredients, instructions, prep/cook times, and servings
- **Meal Planning**: Plan meals for specific dates with different meal types (breakfast, lunch, dinner, snacks)
- **Shopping Lists**: Generate and manage shopping lists linked to households
- **Expense Tracking**: Track food-related expenses per household
- **JWT Authentication**: Secure API endpoints with JSON Web Token authentication

## Tech Stack

- **Framework**: Laravel 12
- **PHP**: 8.2+
- **Authentication**: JWT (php-open-source-saver/jwt-auth)
- **Database**: MySQL

## Key Features

- User authentication and authorization
- Household-based data organization
- RESTful API endpoints
- Ingredient and pantry item management
- Recipe creation with ingredient lists
- Meal plan scheduling
- Shopping list generation and management
- Expense tracking per household
